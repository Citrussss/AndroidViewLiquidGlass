# 源版实机对比记录

设备：Samsung SM-S9010（R5CT50TACFT）。源版：AndroidLiquidGlass 仓库自带 androidApp/release/androidApp-release.apk。两版并排安装。

## 本轮调整
- 首页：主题、分组、字体、间距与透明系统栏；演示页全屏壁纸、居中展示及导航栏留白。
- 按钮：按文字计算宽度、15sp 字体、48dp 高度、16dp 间距、Hue 混色、1.5 倍饱和度、按压放大与拖动反馈。
- 开关和滑条：40×24dp 白色滑块、轨道颜色、双控件联动、1.5 倍按压缩放、折射与透明度过渡。
- 标签：3/4 标签组、源版矢量飞机图标、蓝色选中态。
- 对话框：直接展示、源版文案、按钮、40dp 横向留白、材质参数。
- 锁屏：纹理纵横比、48dp 横向留白、上半屏位置及拖动。
- 控制中心：68/152dp 网格、16dp 间距、背景模糊、展开拖动与重力方向高光。
- 放大镜：文字卡片、光标与镜片联动、1.5 倍放大、80dp 采样偏移。
- 调试面板：256dp 样本、五项参数、底部玻璃面板、折叠和 Reset。
- 自适应亮度：160dp 样本、实时亮度标签与变换手势。
- 渐进模糊：128dp 遮罩区域；两个滚动页改为固定壁纸上滚动 20 张玻璃卡片。
- 渲染：高光不再继承表面透明度；补充加色混合、柔化描边和 Plain 高光。

## 验证
- Debug APK 和设备测试 APK 构建通过。
- CatalogInstrumentation 在设备通过全部 14 个目的地；检查开关、滑条、标签状态、放大镜拖动及两个滚动页渲染变化。
- 实机点击后两个联动开关均为 checked=true。
- 实机 Reset 后五项参数恢复默认，玻璃样本恢复默认形状。
- 最新 APK 已覆盖安装，源版保留供继续对照。
- 原版和 View 截图保存在本目录；view-page-* 是回归过程中的阶段截图，未全部重新生成于最终修改后。

## 尚未完成的验收
不能将功能回归通过等同于逐像素和逐帧完全一致。当前尚需进一步验证：不同主题与旋转后的布局、所有弹簧运动的逐帧轨迹、连续圆角轮廓、阴影精确分布，以及多指变换的惯性和采样细节。没有据此宣称完全一致。

## Bottom Tabs 透视采样专项修复

- 独立 56dp 采样轨道，不再复用可见 64dp 轨道的导出表面。
- 采样轨道随按压启用 24dp 折射，并绘制单独的蓝色图标/文字内容；选中镜片再次对其折射。
- 可见轨道缩放与选中镜片缩放分离，解除选中镜片被轨道圆角裁剪的问题。
- 按实际录屏抽取拖动中同位置帧，核对源版镜片上下缘折射带。
- 图标保持 24dp 原始大小，并补齐图标区域与文字间距。
